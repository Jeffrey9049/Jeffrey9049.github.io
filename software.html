Research and educational resources

Software

Lightweight, CPU-friendly Windows tools that make sign language data processing and machine learning accessible to researchers, students, and educators without extensive programming experience or a dedicated graphics card.

Both applications are available in English and Traditional Chinese (繁體中文), with separate Windows downloads below.

Tools

01 / Video and motion data

Landmark Studio

Version 1.2.0 · English / 繁體中文

A lightweight application for extracting hand, body, and facial landmarks from recorded video. It uses a graphical interface and is designed to run without a dedicated GPU or custom tracking scripts.

  • Video-based landmark extraction
  • Selectable tracking components
  • Structured output for further analysis

Why I Develop These Tools

Technical barriers often make AI difficult to use in sign language research. People who understand sign language and linguistic annotation may not be familiar with programming, while technology developers may not have the same domain knowledge. I develop these tools to help connect those communities and support more independent experimentation by sign language experts.

My goal is to lower both the technical and hardware barriers to participation: no programming is needed for the intended workflows, and neither application requires a dedicated graphics card. Actual performance depends on the computer and the size of the video or dataset. The current Windows releases are available through the download links above.
