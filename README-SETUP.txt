FILES TO UPLOAD
- index.html                 Home (profile, interests, experience/education, papers)
- research.html              Research
- publications.html          Publications
- sign-language.html         Taiwan Sign Language Research
- styles.css                 Site-wide style
- portrait-placeholder.svg   Temporary portrait shown until photo uploaded
- favicon.svg                Browser tab icon

HOW TO DEPLOY
1. Open https://github.com/Jeffrey9049/Jeffrey9049.github.io
2. Add file -> Upload files.
3. Upload the seven files listed above to the repository root (not a subfolder).
4. Commit changes. Existing files with the same names should be replaced.
5. Leave Settings -> Pages on main / (root).
6. After deployment, open https://jeffrey9049.github.io/ (Ctrl+F5 if cached).

ADD YOUR ACTUAL PORTRAIT
- Crop your image to a portrait ratio, ideally 800x1000 pixels.
- Name it profile.jpg and upload it to the repository root.
- The Home page automatically displays profile.jpg if it exists.
- Until the photo is uploaded, the site displays a neutral placeholder image.

OPTIONAL CV LINK
- Upload CV.pdf to the repository root.
- Add <a href="CV.pdf" target="_blank" rel="noopener noreferrer">CV</a>
  to the header navigation if you wish.
