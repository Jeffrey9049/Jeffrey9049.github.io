DEPLOY TO GITHUB PAGES (using GitHub's website)
1. Unzip this archive.
2. Open the existing Jeffrey9049.github.io repository.
3. Click Add file > Upload files.
4. Drag these FIVE files into the upload area:
   index.html, research.html, sign-language.html, styles.css, script.js
   (Don't upload the ZIP itself.)
5. Commit the changes to main. Confirm replacing index.html when asked.
6. The existing Pages setup 'Deploy from a branch' / 'main' / '/(root)'
   should continue working without modification.
7. Wait for the Pages build to finish in Actions, then reload the live URL.
