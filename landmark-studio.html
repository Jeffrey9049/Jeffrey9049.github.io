Software/Landmark Studio

Video analysis software

Landmark Studio

A lightweight, CPU-friendly graphical application that converts video into structured body, hand, and face landmark data without programming or a dedicated graphics card. Available for Windows and macOS.

Overview

Landmark Studio is designed to simplify the preparation of movement data for sign language research. Instead of requiring users to install and write code for pose-estimation libraries, it provides a more approachable interface for selecting video input and the landmarks relevant to a study.

The tool aims to run on standard computer hardware without requiring a dedicated graphics card. By reducing setup complexity and hardware requirements, it helps more sign language researchers, educators, and students explore motion analysis. Processing time can vary with the length and resolution of videos.

The tool supports preparing landmark-based datasets, inspecting captured motion, and introducing video-based tracking methods in teaching.

Typical Workflow

  1. 01

    Choose a video

    Use a recorded signing sample as the source for motion analysis.

  2. 02

    Select landmarks

    Choose the relevant tracking components, including hands, pose, or face.

  3. 03

    Prepare research data

    Use the extracted landmark information in a structured form for subsequent analysis.

Applications

  • Building landmark-based sign language datasets
  • Introducing motion tracking in hands-on workshops
  • Preparing visual features for downstream machine learning experiments
